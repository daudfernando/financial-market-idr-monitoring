11. MENUNJUKKAN KAFKA SECARA LANGSUNG (1 MENIT)
Setelah minimal tiga pesan replay terkirim, buka PowerShell kedua:
Set-Location "C:\Purwadhika\Final Project"
.\show_kafka.cmd

Command memilih topic incremental terbaru di broker, menampilkan metadata
(partition/leader), lalu membaca ulang tiga pesan LANGSUNG DARI KAFKA.
Tunjukkan Topic, Partition:0, Offset:0/1/2, simbol, dan isi JSON pesan.
Ini bukan pembacaan dari file atau BigQuery. Command tidak menulis ke warehouse.
Bisa dijalankan lagi untuk menunjukkan pesan masih tersimpan di Kafka.

Narasi: "Di sini terlihat pesan benar-benar tersimpan dalam topic Kafka.
Offset menunjukkan posisi pesan pada partition. Pembaca terpisah ini dapat
membaca pesan yang sama lagi, tanpa meminta producer mengirim ulang."

Jika ada beberapa demo bersamaan, pilih topic persis dari report run:
.\show_kafka.cmd --topic market.incremental.ISI_RUN_ID_HURUF_KECIL

File implementasi:
- compose.streaming.yaml: service broker Kafka (container, port, retention).
- streaming/producer.py: Producer.produce() mengirim pesan ke Kafka.
- streaming/incremental_demo.py: membuat topic; Consumer.poll() menerima pesan;
  kemudian validasi, raw GCS, dan streaming insert BigQuery.
- scripts/show_kafka.py: pembaca bukti demo terpisah melalui Kafka CLI.

Kafka lokal tidak memiliki GUI web khusus pada setup ini. Docker Desktop
memperlihatkan container broker; show_kafka.cmd memperlihatkan ISI broker.
Retention dikonfigurasi 24 jam, sehingga pesan lama dapat kedaluwarsa;
jalankan replay baru sebelum demo. Jika belum tiga pesan, command pembaca
menunggu paling lama sesuai timeout Kafka CLI lalu dapat berakhir gagal.
